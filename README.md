# Generador de Esquemas Técnicos (SPAT / Perímetro / Torre)

Aplicación web estática en HTML5, CSS y JavaScript (`<canvas>`) para generar esquemas técnicos de sitios de telecomunicaciones y descargarlos en formato PNG:

1. **F12M - SPAT**: Diagrama de puesta a tierra con configuración de pozos (`PT01`–`PT06`), telurómetro y mediciones de resistencia (`50%`, `60%`, `70%`).
2. **Esquema 1 - Perímetro**: Plano rectangular proporcional con puerta de acceso, cotas exteriores en metros y coordenadas inclinadas en las 4 esquinas (`A`, `B`, `C`, `D`).
3. **Esquema 2 - Torre**: Elevación proporcional con 8 modelos de estructura, cotas de altura total, base/pedestal, roldanas, edificio sin parapeto y escalera gato.

## Despliegue en GitHub Pages

1. Sube todos los archivos de este paquete a la raíz de tu repositorio en GitHub.
2. Ve a **Settings → Pages**.
3. En **Source**, selecciona **Deploy from a branch**, elige la rama `main` y la carpeta `/ (root)`.
4. Guarda los cambios y abre la URL pública generada por GitHub Pages.
