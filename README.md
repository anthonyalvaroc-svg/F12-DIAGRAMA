# Generador de Esquemas Técnicos (SPAT / Perímetro / Torre)

Aplicación web estática en HTML5, CSS y JavaScript (`<canvas>`) para generar esquemas técnicos y descargarlos en formato PNG:

1. **F12M - SPAT**: Diagrama de puesta a tierra con configuración de pozos (`PT01`–`PT06`), telurómetro y mediciones de resistencia.
2. **Esquema 1 - Perímetro**: Plano rectangular proporcional con puerta de acceso, cotas exteriores en metros y coordenadas inclinadas en las 4 esquinas (`A`, `B`, `C`, `D`).
3. **Esquema 2 - Torre**: Elevación proporcional con los 8 modelos de estructura y sus cotas específicas.
